# 数学 計算ドリル（index.html）

数学IA・IIB の計算問題を1問ずつ表示するスマホ向け単一HTML。
**GPTがこのリポジトリで行ってよい作業は「問題の書き換え」だけ。** 編集前にこのREADMEと `index.html` の現在の全文を読むこと。

## 1. index.html の構造

ファイルは `index.html` の1つだけ（HTML・CSS・JSを同居。外部依存は cdnjs の KaTeX 0.16.9 のみ）。上から順に次の4ブロックで構成される。

| 順 | ブロック | 内容 | 編集 |
|---|---|---|---|
| 1 | `<head>` | viewport、KaTeXのCSS/JS読み込み | 禁止 |
| 2 | `<style>` | 見た目（スマホ幅・折り返し・ダークモード対応） | 禁止 |
| 3 | `<body>` | 骨組み（下記） | 禁止 |
| 4 | `<script>` | **上半分＝問題データ（`PROBLEMS`）／下半分＝UIロジック** | `PROBLEMS`のみ可 |

### body の骨組み
- `#pos` `#fill` … 進捗表示（「3 / 20」とバー）
- `#quiz` … 出題画面。左ボタン`#prev`・中央`#view`・右ボタン`#next`
- `#answers` … 解答一覧（最初は非表示）
- `#copy` … 最下部の小さなコピーボタン
- `#plain` … AI用の単純テキストを入れる隠し`<pre>`（画面上の占有ほぼゼロ）

### script の構造
`<script>` 内のコメント `/* ===== 問題データ ... ===== */` から `const PROBLEMS = [ ... ];` までが**問題データ**。`/* ===== ここから下はUIロジック ===== */` より下は**UIロジックで触らない**。

主な関数（すべて `PROBLEMS` を読むだけ）:
- `show()` … 現在の問題（`i`番）を描画。`i`が問題数に達すると「解答を表示」ボタンの終了画面を出す
- `card(p, n, withAns)` … 1問分のカードを作る（科目・単元・問題文`q`・式`m`、解答表示時は`a`も）
- `showAnswers()` / `restart()` … 解答一覧の表示／最初に戻る
- `plain(withAns)` … コピー用テキストを `PROBLEMS` から自動生成
- `typeset(root)` … `m`と`a`は KaTeX のディスプレイ数式、`q`内の `$...$` はインライン数式として描画

**問題数・進捗・コピー用テキスト・解答一覧はすべて `PROBLEMS` から自動生成される。** 問題を変えても、他の場所を直す必要はない。

## 2. GPTの作業範囲

- 編集してよいのは `const PROBLEMS = [ ... ];` の**配列の中身だけ**。
- それ以外（head・style・body・UIロジック・このREADME）は、ユーザーが明示的に頼まない限り**1文字も変えない**。
- 作業は差分編集で行う。全文を再出力する場合も、`PROBLEMS`以外は元のまま完全に維持する。
- 新規ファイル・外部ライブラリ・フレームワークを追加しない。
- 問題数は既定で20問（数学IA 10問→数学IIB 10問の順）。増減・配分変更は、ユーザーが指示したときだけ行う。

## 3. 問題の書き方

1問 = 1オブジェクト。配列の順番が出題順。

```js
{c:'数学IA', t:'展開', q:R`次の式を展開せよ。`, m:R`(x+3)(x-5)`, a:R`x^2-2x-15`},
```

| キー | 内容 | 必須 |
|---|---|---|
| `c` | 科目。`数学IA` または `数学IIB` | 必須 |
| `t` | 単元名（短く） | 必須 |
| `q` | 問題文。文中の短い数式だけ `$...$` で囲む | 必須 |
| `m` | 問題の式。**LaTeXのみ（`$`で囲まない）**。画面中央に独立表示 | 任意 |
| `a` | 答え。**LaTeXのみ（`$`で囲まない）** | 必須 |

### 記法ルール（これを破ると画面が壊れる）
1. 文字列は必ず `R` + バッククォート（`String.raw`）で書く。バックスラッシュは1本（`\frac`。`\\frac`は不可）。
2. 文字列の中に バッククォート `` ` ``、`${`、`</script>` を書かない。
3. 各オブジェクトの末尾はカンマ。最後の1問だけカンマなし。波括弧・バッククォートを閉じ忘れない。
4. 長い式・分数・積分・複数の答えは `m` / `a` に入れる。`q` 内の `$...$` は短い式だけ。
5. 答えが複数ある場合は `\begin{gathered}A\\ B\end{gathered}` で縦に並べる。
6. 数式の中に日本語を入れない。度は `60^\circ`、空白は `\ `、積分の `dx` は `\,dx`。
7. 問題文はスマホで2〜3行以内。答えが一意に決まる単純な計算問題にする。

## 4. 手順とチェック

1. `index.html` の現在の内容を取得する。
2. `PROBLEMS` の該当オブジェクトだけを書き換える（全問入れ替えのときは配列の中身全体）。
3. **答えを2回、別の方法で検算**して、問題と答えが一致していることを確認する。
4. 下記チェックを確認してコミットする。
5. コミットメッセージは日本語で1行（例: `問題: Q5・Q12を差し替え`）。
6. ユーザーへは「変更した問題番号・新しい問題・コミット内容」を簡潔に報告する。

### コミット前チェック
- [ ] `PROBLEMS` の外を変更していない
- [ ] すべての `q` `m` `a` が `R`＋バッククォートで書かれている
- [ ] `m` と `a` に `$` が入っていない
- [ ] `c` が `数学IA` / `数学IIB` のどちらか
- [ ] 検算した
- [ ] JSの構文（カンマ・括弧・バッククォート）が正しい
